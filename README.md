# LSCM — NPTEL Logistics & Supply Chain Management

Week-by-week study notes and self-test quizzes for the NPTEL course *Logistics & Supply Chain Management* (Prof. Vikas Thakur, IIT Kharagpur).

Every week comes in two formats:

- **PDF notes** (`pdf/` folder): A4, printable. Notes built only from that week's lecture slides (every point tagged with its slide number), original slide figures, a cheat sheet, slide quirks, practice questions and an answer key.
- **HTML page**: the same notes with an interactive quiz (Practice and Test modes). Download and open in any browser.
