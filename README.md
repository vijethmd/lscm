# LSCM — NPTEL Logistics & Supply Chain Management

Week-by-week study notes and self-test quizzes for the NPTEL course *Logistics & Supply Chain Management* (Prof. Vikas Thakur, IIT Kharagpur).

Each page is a single self-contained HTML file: notes built only from that week's lecture slides (every point tagged with its slide number), a cheat sheet, a list of slide quirks, and a quiz with Practice and Test modes. Open any file in a browser.
